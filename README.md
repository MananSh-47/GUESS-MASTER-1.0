# GUESS-MASTER-1.0
A C-based number guessing game with difficulty levels, scoring and file handling.

GUESS MASTER is a console-based number guessing game developed using the C programming language.

The program generates a random number, and the player has to guess it with the help of hints provided by the game.
## Features

- Random number generation
- Interactive guessing system
- Higher and lower hints
- Number of attempts tracking
- Performance-based feedback
- Option to play again

## Technologies Used

- C Programming Language
- Standard C Libraries

## Concepts Used

- Variables and data types
- Conditional statements 
- Loops 
- Random number generation 
- User input and output
- File handling 
- Arrays and strings 

## How to Run

1. Download the `GuessMaster.c` file.
2. Open it in a C compiler or IDE.
3. Compile and run the program.
4. Follow the on-screen instructions to play.
